# Project instructions for Codex

Always answer the user in Russian.

This is a Go Telegram bot project.

Use concise technical answers.
Prefer simple Go code and explicit logic.
Avoid overengineering.
Do not use in-memory timers.
Do not use background infinite loops.
Do not use polling for Telegram.
Use Telegram webhook.
Use MongoDB Atlas as the database.
Use UTC in the database.
Display dates in Europe/Kyiv timezone.
All elapsed time must be calculated from stored timestamps.
Do not add a web UI in MVP.
